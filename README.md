Aawaz-Adhikar

About the Project

Aawaz-Adhikar is a web-based platform developed to help users raise their concerns, access relevant information, and make their voices heard. The project aims to provide a simple and user-friendly digital platform.

Features

- User-friendly web interface
- Django-based backend
- Organized application structure
- Database integration
- Web-based access to platform features

Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

Project Structure

- "core/" – Main application files
- "config/" – Django project configuration
- "manage.py" – Django management utility
- "db.sqlite3" – SQLite database

Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/khushi180505-beep/Aawaz-Adhikar

2. Navigate to the project directory:
   
   cd Aawaz-Adhikar

3. Create and activate a virtual environment:
   
   python -m venv venv

4. Install dependencies:
   
   pip install django

5. Run database migrations:
   
   python manage.py migrate

6. Start the development server:
   
   python manage.py runserver

7. Open in your browser:
   
   http://127.0.0.1:8000/
